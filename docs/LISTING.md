## Long description

> Most "meal planner" templates generate recipes and leave the user to
> shop for everything. PantryPal's whole premise is the opposite: **it
> plans meals around what's already in your kitchen.** That's the pitch,
> and it's fully implemented, not a mockup.

**What you're getting:**

A complete, production-quality React 19 + TypeScript source tree for a
mobile-first meal-planning PWA — five full sections, a working
recommendation engine, and full English/Italian localization. No
placeholder screens, no "coming soon" states, no backend or API keys
required to run it locally or deploy it live today.

**Included out of the box:**
- Guided onboarding (household, diet, allergies, cuisines, meal styles)
- Searchable ~150-item pantry/fridge/freezer inventory
- A real recipe-matching engine — not random selection — that filters by
  diet restriction and allergy (hard filters, safety-first), scores by
  cuisine preference, ingredient availability, and expiring stock
- 51 fully-written recipes across 13 cuisines, each with steps, nutrition,
  allergens and substitutions
- Automatic "have vs. need to buy" breakdown and one-tap shopping list
  generation
- School & work packed-lunch planners
- Full English + Italian translation layer you can extend to any language
  in an afternoon
- Installable PWA, offline-capable

**Built to grow:** the data model is shaped for the natural next steps —
swap `localStorage` for a real backend, plug an LLM into the single
recipe-generation seam, add barcode scanning to the inventory screen.
None of that requires restructuring what's here.

**Tech stack:** React 19, TypeScript (strict mode), Vite 8, Tailwind CSS
v4. Clean lint (`oxlint`), clean type-check, verified with automated
end-to-end browser testing in both languages.

**What you won't get:** a backend, hosted database, user accounts, or
payment processing — this is a front-end product template, priced and
scoped accordingly. See the roadmap section in the README for what
that next phase looks like.

## Suggested pricing

Two tiers, matching `LICENSE.md`:

| License | Suggested price | Use case |
|---|---|---|
| Regular | **$59–$79** | One end product, personal or single client |
| Extended | **$199–$249** | Product resold/sublicensed to multiple end users (SaaS, white-label) |

**Why this range:** comparable polished single-purpose React/Vite app
templates on CodeCanyon/ThemeForest-style marketplaces cluster around
$40–$120 for a Regular license when they include this much working
functionality (not just UI mockups — an actual working
filter/recommendation engine and full i18n are above what most
"UI kit" templates offer). Price at the top of that range ($69–$79) given
the working recipe engine and dual-language support are genuine
differentiators most competing templates don't have; $199+ for Extended
is standard practice (roughly 2.5–3x Regular) rather than tied to any
specific value calculation.

If you'd rather sell it as a single no-tiers purchase (e.g. plain
Gumroad listing), **$79** is a reasonable single price point.
